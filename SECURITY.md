# Security policy

The public MCP endpoint is read-only and does not accept credentials. Please do
not include personal data, API tokens, private keys, or confidential company
information in tool arguments or reports.

Report a vulnerability through GitHub’s private vulnerability reporting for
this repository. Include the affected endpoint, impact, and minimal reproduction.
Do not open a public issue for an unpatched vulnerability.

Supported metadata version: `1.0.x`. Operational incidents and data corrections
can also be reported from the links on the
[TexasRatedPros MCP page](https://www.texasratedpros.com/mcp).
